# Middle-earth Skills

从课内学习、简洁笔记，到论文精读与研究关联的一组中文 AI Skills。

AI 提供材料定位、解释、练习、追问和笔记框架；学习者亲自完成解题、推导与研究判断。名称受托尔金笔下人物启发，本项目与相关权利方无官方关联，不包含原作图片或文本素材。

## 选择一个 Skill

| Skill | 适用需求 | 默认交付 | 能力范围 |
|---|---|---|---|
| [Elrond · 课内学习教练](skills/elrond/SKILL.md) | 理解课件、练习、订正、检查掌握情况 | 一题一问、逐步提示、变式与反向教学 | 依据真实作答调整，不虚构跨会话记忆 |
| [Idril · 简洁笔记](skills/idril/SKILL.md) | 整理教材与课件，准备纸质复习笔记 | 核心结论、条件、必要推导和典型例题 | 沿用材料符号，支持带练或整份交付 |
| [Galadriel · 论文精读与复现准备](skills/galadriel/SKILL.md) | 理解单篇论文的问题、公式、方法与证据 | 原文定位、推导提示、追问和可填写的学术笔记框架 | 支持复现线索整理，尚无完整复现执行流程 |
| [Eärendil · 文献阅读与研究关联](skills/earendil/SKILL.md) | 组织文献阅读，检查与当前研究问题的关系 | Obsidian Markdown 空白框架、客观信息、证据定位和问题 | 个人分析、评价、研究联系和 Related Work 默认由用户填写 |

初次使用只选最贴近当前需求的一个。课程学习可先用 Elrond 练习，再用 Idril 整理；论文阅读可先用 Eärendil 确定关注点，再用 Galadriel 深读关键内容，最后由自己完成同一份笔记。

## 安装与开始使用

本仓库包含指令与模板，没有常驻程序。以下是本地 Codex 的文件安装方式；其他支持 Skills 的客户端请参照各自文档，不能保证目录、展示配置和工具能力完全通用。

1. 下载仓库 ZIP 并解压，或通过 Git 克隆仓库。
2. 选择 `skills` 下需要的文件夹，将整个文件夹复制到用户技能目录。Codex 默认可使用 `~/.codex/skills/`；自定义了 `CODEX_HOME` 时使用对应的 `skills` 目录。保留文件夹内的 `agents`、`assets` 和 `references`。已有同名 Skill 时先比较或备份，避免覆盖个人版本。
3. 在能访问本地文件的 Codex 对话中确认该 Skill 可用，然后使用 `$elrond`、`$idril`、`$galadriel` 或 `$earendil` 发起任务。客户端未列出时，按其说明刷新或重新打开对话，也可以提供安装后的完整 `SKILL.md` 路径，要求先实际读取再使用。

Windows 默认目录示例为 `%USERPROFILE%\.codex\skills\elrond\SKILL.md`。本仓库不自动修改你的本机技能目录。网页或云端聊天不会因为电脑上有文件就自动获得访问能力。

### Elrond

适合预习、逐页学课件、概念理解与题目训练。八种模式包括真实试错、困惑破解、学习路径、漏洞检测、进度复盘、模考、解题依据检查和反向教学。按状态切换，不会一次全部展开。用户要求直接解答、完整解析或加快进度时可以调整。

```text
使用 $elrond，依据这份课件第 10—15 页带我学习。每次一个问题，按真实回答提示，订正后用变式检查迁移。
```

```text
使用 $elrond，我来讲解链表删除，你扮演初学者，每次追问一个问题，检查空表、头结点、指针更新和内存释放。
```

提供课件、题目或教材范围即可开始；有考试目标与时间限制时一并说明。进度评价只使用可访问的真实记录，提示后完成不等于独立掌握。

### Idril

适合课后整理和考前复习。保留概念、公式条件和易错点，沿用原材料的符号；每个核心知识点默认配 1–2 道有来源标记的典型题。带练时先让用户尝试，要求完整笔记时一次交付指定范围。

```text
使用 $idril，把这一章整理成适合手抄的复习笔记，沿用讲义符号，写清公式条件，原题、改编题与自拟题分别注明。
```

```text
使用 $idril，依据讲义第 12—18 页带我复习，先给一个知识点和一道题，到第 18 页停止。
```

输出在聊天中渲染公式，不要求四色笔配置，不自动生成图片。来源不可访问时说明缺失内容，不假装已经阅读。

### Galadriel

适合单篇深读：核对版本、梳理必要研究脉络、补基础与推导、重建方法、检查关键实验，再提出可证伪的问题。默认每次聚焦一个概念或推导步骤，使用 1–3 个 Grill Me 问题检查理解。

```text
使用 $galadriel 陪我深读这篇论文，先核对问题和版本，给出第一处阅读位置和问题，等我解释后再推进。
```

```text
使用 $galadriel，检查关键公式和消融，并整理已核实的代码、数据、依赖、预算与缺失信息，不执行训练。
```

提供论文 PDF 或原文链接；涉及实现时附官方代码与配置。可按需使用 [LaTeX 空白模板](skills/galadriel/assets/paper-notes-template.tex)，生成 PDF 才需要中文字体与 LaTeX 环境。模板采用 Fandol 字体配置，需要相应字体包；编译前检查环境并在生成后检查页面。本发布包尚未执行模板编译验收。

当前不包含环境锁定、训练运行、指标对齐和复现报告的完整执行流程，不能将复现准备称为已经完成复现。

### Eärendil

适合论文或技术博客的定向阅读。模板覆盖任务、问题、机制、反馈与记忆、改变位置、研究联系、差异、baseline 或消融、Related Work，以及有价值的 Grill Me Q&A。检查公平比较、参数更新和结论范围，保留读者独立判断。

Q&A 只整理真正暴露误解、改变理解或影响研究决策的实际问答，保留初答、关键追问、修正与原文依据。用户回答与 AI 的解释分开记录，未回答或未形成的判断留空，不把聊天中的一致意见当成已验证结论。

```text
使用 $earendil，为这篇论文搭建 Obsidian 空白框架，只填书目信息、材料链接和阅读位置，分析与问题答案由我写。
```

```text
使用 $earendil，审阅我已有的笔记，检查原文依据、baseline 公平性和结论范围，只在聊天里给修改建议。
```

```text
使用 $earendil，把刚才真正有价值的 Grill Me 问答整理进笔记，保留我的初答、关键追问和实际修正，标出 AI 的解释与原文依据，未回答的部分不要代填。
```

按需在自己的副本中填写 [研究画像](skills/earendil/references/research-interests.md)。不填也能阅读文献；未确认的项目接口保持待确认。框架是普通 Markdown，可以放入 Obsidian，也可以在其他编辑器使用。

另提供可独立复制的 [跨学科文献阅读模板](skills/earendil/assets/interdisciplinary-note-template.md)，适用于理论、实证、定性、历史与文本诠释、规范论证等研究。围绕问题、前提、方法、依据和结论组织，按研究方式选用字段，保留有价值的 Grill Me Q&A；不要求安装 Skill，也不替换原有 AI 研究模板。

## 依赖与可选工具

基础需求是能够读取这些指令的 AI 客户端，以及用户提供的可读材料。联网核查、PDF 提取、代码执行和文件写入取决于宿主环境；缺少工具时应说明限制。

Zotero、浏览器翻译扩展、Obsidian、LaTeX 和模型 API 按需选择，不必全部安装。参见 [可选阅读工具与两条使用路线](docs/optional-reading-tools.md)。

本仓库暂未授予额外的开源许可证；正式选择许可证前，公开可见不等于允许任意修改与再分发。第三方工具遵循各自许可证。欢迎通过 Issues 报告触发问题的材料范围、使用指令、实际表现和预期表现，请勿上传个人密钥或未公开资料。
