# 跨学科文献阅读笔记

适用于论文、学术专著章节、研究报告及有明确论证的学术文章。围绕研究问题、论证方式、证据和结论组织，不预设所有研究都需要实验、算法或因果识别。

按材料选择相关字段，不要求每项填满；不适用处标 N/A 或删去。只读了部分内容时标明覆盖范围，暂未找到的信息写“待核实”，不要用学科常识补造原文。方法名称相同不代表不同学科的评价标准相同。

个人分析与研究判断由读者完成。AI 可以提供客观书目信息、材料定位、解释和追问；按请求整理实际讨论时，区分读者回答与 AI 建议，未形成的回答留空。

## 2. 研究问题与学术位置

作者试图回答什么问题？研究对象、时间与空间范围是什么？它是在描述现象、解释过程、估计关系、推导性质、诠释材料，还是评价应当如何行动？允许多种目标并存，但需分别说明。

它回应了哪场争论、哪类既有解释或实践困难？代表性前作如何回答，作者认为还有什么未解决？区分作者对前人的描述与自己核查过的情况，不仅凭“首次”“填补空白”等表述判断贡献。

- 一句话概括研究问题：
- 学术争论 / 既有路线及原文位置：
- 作者声称的贡献：[新问题、新材料、新概念、新解释、新方法或其他]

## 3. 核心概念、前提与立场

哪些术语决定了论证能否成立？记录作者的定义、操作化方式或语境含义，避免用自己熟悉的学科定义替换。哪些是定义、经验假设、数学假设、解释前提或价值立场？哪些前提明确写出，哪些只是我的推断？

## 4. 研究如何展开

沿作者实际做法说明：从什么材料或前提出发，经哪些操作、推理或解释，得到什么结果？写出关键步骤及其理由，不只列方法名称。

以下是可选检查方向，只保留与本文相关的部分；混合方法研究可结合使用。

| 研究方式 | 重点核对 |
|---|---|
| 理论、数学或形式化研究 | 定义、公理与假设；命题如何推出；证明关键步骤、反例和成立条件；形式结果如何对应实际问题 |
| 实验、测量或定量观察研究 | 样本与测量、研究设计、比较对象、分析方法和不确定性；涉及因果主张时再检查识别条件与混杂解释 |
| 定性、访谈、民族志或案例研究 | 选例与进入现场的方式、材料生成过程、研究者位置、分析或编码依据、反例材料，以及解释如何从材料中形成 |
| 历史、文本或人文诠释研究 | 史料与版本、来源和语境、材料选择、诠释步骤、互证或冲突材料，以及竞争解释 |
| 哲学、伦理或规范论证 | 概念区分、前提与推理、价值依据、思想实验、反驳及回应；描述事实是否足以支持规范结论 |
| 综述或综合研究 | 文献范围与纳入依据、检索或选文过程、不同研究如何比较与综合、遗漏和异质性；叙述性综述不机械套用系统综述要求 |
| 设计、工程或实践导向研究 | 使用情境、需求与约束、方案选择、评价标准、失败情形及实际使用证据 |

- 最影响结论的一项方法选择及理由：
- 复核需要的材料 / 数据 / 代码 / 推导 / 研究记录：[按学科适用；未公开不等于已经证明有问题]

## 5. 关键结果与论证依据

选择真正支撑中心结论的结果或论证，不复述所有图表。证据可以是观察、统计估计、证明、史料、文本细读、案例对照或其他形式；说明它凭什么支持该主张，而非只记录“作者举了什么例子”。

按需重复以下记录：

- 作者的一项关键主张：

- 它支持到什么程度：[例如特定条件下成立、样本内关系、某种解释的合理性；不要混同]
- 仍可成立的其他解释 / 尚缺的一步论证：

## 6. 可信程度、局限与争议

先重建作者最有力的论证，再判断问题。区分原文已承认的局限、自己有依据的质疑和待检验猜想。批评应对应具体材料或推理，不能仅因研究没有采用另一学科的方法就判定其无效。

- 哪种新材料、反例、论证或检验会改变我的判断：
- 当前不能判断的内容及缺失信息：

## 7. 与我的问题有什么关系

没有自己的课题时，可关联课程问题、实践困惑或后续阅读；允许“暂无直接联系”。跨学科迁移前，先比较概念含义、研究对象、尺度、材料生成方式与评价标准。

## 9. Grill Me Q&A

只保留真正澄清概念、暴露误解、改变证据判断或影响后续研究的实际问答，不记录全部聊天，不凑数量。问题应贴合本文，例如“这个推理在哪个前提下失效？”“哪份材料最能区分两种解释？”“换一个概念定义，结论是否仍然成立？”，不要把所有学科都问成消融或模型性能问题。

- 为什么值得追问：
- 我的初答：[忠实记录实际回答；未回答则留空或标待回答]
- 关键追问与反馈：[明确标注读者与 AI；不把 AI 解释写成我的认识]
- 我的修正与理由：[来自自己的实际表达或明确确认；没有形成则留空]
- 对应原文与证据状态：[位置；区分原文事实、解释、推断和待验证判断]
- 仍未解决的问题及下一步：[没有则省略]
